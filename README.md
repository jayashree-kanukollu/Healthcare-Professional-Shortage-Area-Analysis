
# Healthcare Professional Shortage Area (HPSA) Analysis

## Project Overview
Analyzed Health Professional Shortage Area (HPSA) designations across the United States to identify geographic disparities in healthcare workforce availability and highlight underserved communities.

Developed Tableau dashboards using data from the Health Resources and Services Administration (HRSA), with a detailed focus on North Carolina.

## Tools and Technologies
- Tableau
- Microsoft Excel
- Data Cleaning and Preparation
- Geographic Data Visualization
- Healthcare Workforce Analytics

## Dataset
**Source:** Health Resources and Services Administration (HRSA) Data Warehouse

- National dataset containing 19,000+ records
- North Carolina subset containing 567 active shortage designations
- Geographic coverage: U.S. states and counties
- Key variables: State, County/Facility, HPSA Discipline Class, HPSA Score, and Designation Type

Official data portal: https://data.hrsa.gov/

## Methodology
1. Reviewed and prepared HPSA designation data for geographic analysis.
2. Filtered the national dataset to examine active designations in North Carolina.
3. Compared HPSA scores across U.S. states and healthcare disciplines.
4. Created Tableau visualizations to examine geographic patterns and differences in shortage designations.
5. Built national and county-level dashboards to support healthcare workforce assessment.

## Dashboard Components
### US Dashboard
- Geographic map of HPSA designations
- Average HPSA scores by state
- Comparison of shortage scores across healthcare discipline classes

### County Dashboard
- County-level geographic analysis
- Population-based visualizations
- Comparison of shortage designations across counties

## Key Insights
- HPSA scores vary geographically across U.S. states and healthcare disciplines.
- The North Carolina analysis identified 567 active shortage designations in the project's dataset.
- National and county-level visualizations help identify areas for further workforce planning and resource allocation.
